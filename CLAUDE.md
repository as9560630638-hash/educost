# ShikshaPortal — Educational Discovery & Admissions Platform

## Project Overview
This project is a high-end, responsive college discovery and admissions portal inspired by Shiksha.com.

## Workspace Location
`C:\pb projects\Siksha (student data , councelling)\`

## Design System & Tokens
- **Primary Colors**: Shiksha Orange (`#ea580c`), Trust Navy (`#0a192f` / `#0f172a`), Cyan Accent (`#0284c7`), Gold (`#f59e0b`)
- **Background**: Neutral Off-White (`#f8fafc`), Cards (`#ffffff`)
- **Typography**: `Plus Jakarta Sans` (Headings) + `Inter` (Body & Data)
- **Unified Stylesheet**: `shiksha-style.css` (All styles, tokens, and components are defined here. DO NOT create separate CSS files).
- **Interactive Script**: `shiksha.js` (Handles search autocomplete, 5-step modal, college tabs, and compare dock).
